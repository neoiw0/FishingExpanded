## 公式与锚点（2026-08-10 用户确认）

分段线性（Lerp 自带 [0,1] 钳制，0 级与 100 级与原公式一致；2026-08-10 设计修正：新增 50 级锚点 ×20）：

| 等级区间 | 倍数 | 每级增长 |
|---|---|---|
| [0, 4] | 1.0 → 1.2 | 0.05/级 |
| [4, 20] | 1.2 → 5 | 0.2375/级 |
| [20, 50] | 5 → 20 | 0.5/级 |
| [50, 100] | 20 → 50 | 0.6/级 |
| [-10, 0] | 0.5 → 1.0（原线性，不变） | 0.05/级 |

示例值：4级=1.2、5级=1.4375、10级=2.625、15级=3.8125、20级=5、30级=10、40级=15、50级=20、70级=32、80级=38、100级=50。
新曲线在 (0,100) 内全程低于旧线性（1+49×level/100），仅在 0 与 100 重合——即“难度增长整体后移”。
