## 4. Install / Uninstall (English)

### Install

1. Install SMAPI 4.0.0+ and Stardew Valley 1.6+.
2. Download this mod and extract the `FishingExpanded` folder into `Stardew Valley/Mods`.
3. Launch the game with SMAPI.
4. No configuration needed—it works out of the box.

### Uninstall

1. Close the game.
2. Delete the `Mods/FishingExpanded` folder.
3. Your vanilla save is not damaged. Challenge data remains in the save's modData and will return if you reinstall.

### Multiplayer

- In online co-op, **the host and every farmhand must install this mod**.
- Each player's data is saved independently.

## 4. 安装 / 卸载（中文）

### 安装

1. 安装 SMAPI 4.0.0+ 和星露谷物语 1.6+。
2. 下载本 Mod，解压后把 `FishingExpanded` 文件夹放进 `Stardew Valley/Mods`。
3. 用 SMAPI 启动游戏。
4. 无需手动配置，开箱即玩。

### 卸载

1. 关闭游戏。
2. 删除 `Mods/FishingExpanded` 文件夹。
3. 原版存档不会被破坏；挑战数据保留在存档 modData 中，重装后会恢复。

### 联机注意

- 在线联机时，**主机和每一位农场客都必须安装本 Mod**。
- 每位玩家的数据独立保存，互不串写。
