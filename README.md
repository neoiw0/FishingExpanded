# FishingExpanded

A fair, deep, vanilla-feeling fishing expansion for Stardew Valley.

Every species quietly keeps its own opinion of you — catch its fish well and your reputation rises through **12 rank titles**, each fully renamable in `config.json`.

## Highlights

- **Per-species fish reputation** — every species grades you on its own scale (-10 to 100); weak fish just want to spar with you, legends demand respect
- **12 rank titles** to climb, all customizable per slot (see the [guide](CUSTOM-RANK-TITLES.md))
- **61 crowned fish**, giant fish, challenge bait, backable-or-random fish behavior
- **959 bilingual flavor lines** — all 51 townsfolk can praise your catch in their own words (10 lines each), plus a 100-line generic pool
- **Fair by design** — the three vanilla fishing festivals stay completely vanilla unless you opt in; opt-in festival scoring multiplies by your quantity bonus
- **17 unique mechanics** in total, tuned over 100+ recorded playtest sessions

## Requirements

- Stardew Valley 1.6+
- SMAPI 4.0.0+
- For online play: the host and every farmhand must install the mod

## Install

1. Install SMAPI and launch the game once.
2. Unzip the release into `Stardew Valley/Mods`.
3. Start the game through SMAPI. No extra setup needed.

# FishingExpanded（中文）

一个公平、耐玩、深度融入星露谷原版的钓鱼扩展。

每个种群都会偷偷给你记一笔评价——钓得越好，声誉越高，一路解锁 **12 个职阶称号**，而且全部可以在 `config.json` 里改名。

## 亮点

- **逐鱼种声誉系统**——每种鱼按自己的标准给你打分（-10 到 100）；平庸个体只想找你练练手，传奇则要求你拿出真本事
- **12 个职阶称号**逐级攀登，每一格都可自定义（见[指南](CUSTOM-RANK-TITLES.md)）
- **61 条皇冠鱼**、巨型鱼、挑战鱼饵、可背板/全随机两种行为模式
- **959 条双语文案**——全部 51 位镇民都能用自己的口吻夸你的渔获（每人 10 条），另有 100 条通用夸奖池
- **公平优先**——三个原版钓鱼节日默认完全原版；主动开启后节日积分才按数量倍数加成
- 共 **17 项独有机制**，历经 100+ 条实测记录打磨

## 环境

- 星露谷物语 1.6+
- SMAPI 4.0.0+
- 在线联机：主机和每位农场客都必须安装本 Mod

## 安装

1. 先安装 SMAPI，并至少启动一次星露谷。
2. 把压缩包解压到 `Stardew Valley/Mods` 文件夹。
3. 用 SMAPI 启动游戏，无需额外配置。
